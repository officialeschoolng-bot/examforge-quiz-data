Projectile Motion

If they ask for… Use this
Time to max heightt = U sinθ / g
Total time of flightT = 2U sinθ / g
Maximum heightH = U² sin²θ / (2g)
RangeR = U² sin 2θ / g
Max range (45°)Rmax = U² / g
Horizontal projectile: time to fallt = √(2h / g)
Horizontal projectile: horizontal distanceS = ux t

Motion (Constant Acceleration)

If they ask for… Use this
Final velocityv = u + at
Distances = ut + ½at²
Velocity without timev² = u² + 2as
Average velocityvavg = Δx / Δt
Average accelerationaavg = Δv / Δt
Free fall downwardv = u + gt, h = ut + ½gt², v² = u² + 2gh
Thrown upwardv = u − gt, h = ut − ½gt², v² = u² − 2gh

Vectors

If they ask for… Use this
Magnitude|A| = √(Ax² + Ay² + Az²)
Dot productA · B = AB cosθ = AxBx + AyBy + AzBz
Cross product magnitude|A × B| = AB sinθ
Work from vectorsW = F · d
Angle between vectorscosθ = (A · B) / (AB)

Momentum & Collisions

If they ask for… Use this
Momentump = mv
ImpulseI = Ft = Δp
Conservation of momentumm₁u₁ + m₂u₂ = m₁v₁ + m₂v₂
Inelastic (stick together)m₁u₁ + m₂u₂ = (m₁ + m₂)v
Explosion / recoilm₁v₁ = −m₂v₂

Gravitation

If they ask for… Use this
Gravitational forceF = Gm₁m₂ / r²
g on a planetg = GM / R²
Gravitational potentialV = −GM / r
Escape velocityve = √(2GM / R) = √(2gR)
Kepler's third lawT² ∝ r³, T² = 4π²r³ / (GM)

Work, Energy & Power

If they ask for… Use this
WorkW = FS cosθ
Kinetic energyK = ½mv²
Gravitational PEPE = mgh
Spring PEPE = ½kx²
Work–energy theoremW = ΔK
PowerP = W / t = Fv

Circular & Rotational Motion

If they ask for… Use this
Centripetal accelerationac = v² / r = rω²
Centripetal forceFc = mv² / r = mrω²
Angular velocityω = v / r = 2π / T = 2πf
Torque (rotational)τ = Iα
Moment of inertia (disc)I = ½MR²
Moment of inertia (solid sphere)I = (2/5)MR²
Moment of inertia (rod, centre)I = (1/12)ML²
Moment of inertia (rod, end)I = (1/3)ML²
Angular momentumL = Iω
Rotational KEKErot = ½Iω²
Rolling total KEKE = ½mv² + ½Iω²
Parallel axis theoremI = Icm + Mh²
Perpendicular axis theoremIz = Ix + Iy

Simple Harmonic Motion

If they ask for… Use this
Spring–mass periodT = 2π√(m / k)
Simple pendulum periodT = 2π√(L / g)
Frequencyf = 1 / T, ω = 2πf
SHM displacementx = A cos(ωt + φ)
SHM velocityv = −Aω sin(ωt + φ)
SHM accelerationa = −Aω² cos(ωt + φ) = −ω²x
Total energy in SHME = ½kA²
